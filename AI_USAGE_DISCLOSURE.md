# AI Usage Disclosure

## Overview
In accordance with the Toucan Engineering Challenge guidelines, this document discloses the use of AI assistance during the completion of this project.

## Scope of AI Assistance
* AI coding assistance (Antigravity AI / Large Language Models) was used to assist with:
  * Initial exploratory analysis of the starter project structure and requirements.
  * Drafting boilerplate code for DTOs, JPA entities, exceptions, and REST endpoints.
  * Constructing unit and integration test scenarios across required edge cases.
  * Reviewing code against requirements and drafting markdown documentation.

## Candidate Verification & Quality Assurance
* All AI-generated code and suggestions were manually reviewed, verified, and validated against the Toucan challenge requirements.
* Business validation rules, finite state machine transitions, and database mappings were thoroughly checked.
* The entire test suite (18 unit and integration tests) was executed locally and confirmed passing with zero failures.
